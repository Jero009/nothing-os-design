Doto weight rule: ≈400–500 keeps dots separate and round; heavy weights smear them together. In OS 5, Doto is never a metric tile — hero display only.

Interaction feedback is haptic, never audible — the click you "hear" on a Nothing phone is the motor. Sound is alarm-only, and it ducks the user's music instead of stopping it. Vocabulary [impl — Essential Island util/HapticStyle.kt]:

Strength is a user setting that scales amplitude (off / light ×0.55 / normal ×1.0 / strong ×1.5) — it never changes the effect choice. Scrub ticks fire only when a selection CHANGES. Platform: predefined effects are Android 10+ with device tuning and automatic fallback; primitive compositions are Android 11+ with none — check support first.
Sound roles
ALERT · TIMER / REST DONE

Duck, don't stop: transient-can-duck focus lowers the user's music, one short cue on the alarm channel, restore volume. [impl — dashbord duckAndDing]

UI TAPS / TRANSITIONS

Nothing. The system UI plays no tap sounds — the haptic carries interaction feedback entirely. Decorative UI sounds are never Nothing.

Nothing hardware — sound becomes light
GLYPH DEVELOPER KIT

The sanctioned path for the "event becomes light" identity: requires an API key from Nothing (unkeyed debug mode auto-expires after 48 h). Glyph Composer is the stock app users already know for sound+light ringtones. Don't fake glyph behavior with screen flashes or sampled sounds.
