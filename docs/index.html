Nothing OS design · measured spec · v1.3.0

Build apps that look Nothing.

A pixel-measured, source-checked design specification for the Nothing OS / Nothing OS 5 visual language — tokens, typography, components, haptics & sound. Nothing publishes no official token spec: everything here is either from Nothing's own materials ([official]) or measured from a real device / working apps ([impl]), audited claim-by-claim.

Element galleryInteractive mockups — dark & light elements, native widgets, app rows, haptic vocabulary. TokensBrand palette, dark/light, OS 5 deltas, complete 2×2 style×mode matrix, accent decision table. TypographyFont roles, type scale, Nothing's official NType82/NDot specs, the OFL stand-ins. ComponentsButtons, switches, chips, dot-matrix icons, media-player patterns, motion, a11y. Haptics & soundPlatform APIs, the semantic haptic vocabulary, alarm-only sound with ducking, Glyph SDK. Case studyMissingCore/Music — a second shipped implementation, cross-checked value by value. Fact-checkClaim-by-claim audit with verdicts and sources — the credibility layer. tokens.json / tokens.cssMachine-readable exports for devs and designers.
